# AI Archive Cleaner

[English](README.en.md)

Codex と Claude Code のローカルチャット履歴・専用保存領域の生成物・ログを削除する Windows 向けGUIツール。日本語OSでは日本語、それ以外では英語で表示します。

## ダウンロードと使い方

[GitHub Releases](https://github.com/Lasagnoa/ai-archive-cleaner/releases/latest) から `AIArchiveCleaner.exe` をダウンロードして起動してください。Windows 10 / 11 対応。

1. タイトルまたは左端のチェック欄をクリックして、削除するチャットを選びます。同名でも別のチャットIDは別項目です。
2. 「削除」で範囲を確認します。毎回、対応する共通ログ・キャッシュと未使用のプロジェクト登録を整理します。
3. すべてのローカルチャットを選んだ場合、または履歴がすでに空の場合は、確認後に対応する残存履歴と一覧も全削除します。検索結果に表示されないチャットも判定に含めます。
4. 稼働中の対象アプリは確認後に終了します。削除のバックアップは作成しません。

## 削除範囲

- **Codex** は会話、索引、既知のSQLite・JSONの履歴、選んだIDに結び付く生成物を処理します。JSONの旧形式、アカウント別の設定、`.codex-global-state.sqlite` のバージョン1に対応します。
- **チャット専用フォルダー** は `Documents/Codex/日付/チャット名` とチャットIDの明示的な対応を確認して削除します。中の Git リポジトリ、未コミット・未追跡ファイルも対象です。登録プロジェクトや残すチャットとの重複、外部の作業先は保護します。
- **プロジェクト登録** は残るチャットのプロジェクトID・作業先を照合して整理します。所属を特定できないチャットがあるときは登録を保持します。全削除では対応する一覧と新規チャットの選択状態を解除します。
- **Claude Code** は標準の保存先と `CLAUDE_CONFIG_DIR` を扱います。会話JSONL、同じセッションのサブエージェント・ツール出力、ファイル履歴、添付画像、索引、入力履歴、対応するDesktopのCodeセッション記録を整理します。プロジェクトのメモリ、MCP・信頼設定、通常のClaude Desktopやクラウドの会話は保持します。[Anthropic の保存先一覧](https://code.claude.com/docs/en/claude-directory)
- ログイン、Cookie、設定、スキル、プラグイン、外部ブラウザー、実際の作業プロジェクトを保持します。所有者不明の添付・共有履歴は個別削除の対象を特定できません。

詳しい対象と制約は [仕様](SPEC.md) を参照してください。

## エラーと未対応領域

- 読み取り専用Gitファイルは、対象ファイルの属性だけを解除して再試行します。ACLや管理者権限を変更しません。
- 削除対象内にあるシンボリックリンク・ジャンクションはリンク自体だけを削除し、リンク先はたどりません。削除対象への途中経路にあるリンクや未知の再解析ポイント、設定・認証フォルダに重なる再帰削除は拒否します。
- 独立した処理はエラー後も継続し、DB/JSON/ファイルを確認します。未知の非空DB・テーブルは削除せず、未対応として報告します。
- `cleanup_backups`、`memories_extensions`、`worktrees` にファイルがある場合は、構成や実作業データの可能性があるため自動削除せず手動確認を報告します。
- 今後追加される任意の保存先・設定と混在した未知のデータまでを、完全消去できるとは保証しません。

## ディスク全体バックアップについて

このツールは対応するローカルファイルとDB内の履歴を整理するもので、媒体の完全消去ツールではありません。SQLiteではsecure_delete、VACUUM、WALの切り詰めを行いますが、削除済み領域、復元ポイント、過去のバックアップ、任意の場所に複製された生成物、クラウド側履歴は対象外です。

バックアップソフトが未使用セクタまで複製するかは別途確認してください。本体のログインを保持するため、アカウントから取得できるクラウド情報は再表示される場合があります。

## 開発・検証・ビルド

ソースのあるフォルダ（`Development` 構成では `Development`）で以下のコマンドを実行します。開発環境と exe のビルドには Python 3.13 を使用します。ソースからの実行には Python 3.11 以降が必要で、実行時の依存は標準ライブラリのみです。

```powershell
py -3.13 -m venv .venv
.\.venv\Scripts\python.exe app.py
.\.venv\Scripts\python.exe -m unittest -v test_cleanup
.\build_exe.ps1 -InstallDependencies
```

既存環境で依存が揃っていれば `.\build_exe.ps1` だけでビルドできます。テストに失敗した場合はビルドを中止します。`Development` からビルドすると、プロジェクト直下の `Release/AIArchiveCleaner.exe` に出力します。単独でクローンしたフォルダでは `dist/AIArchiveCleaner.exe` に出力します。PyInstaller はソースと同じフォルダの `.venv` にインストールします。

テストは隔離されたダミーデータを使い、本物の会話や設定を削除しません。認証・Cookie・設定の保持、旧DB、孤立カタログ、部分失敗、読み取り専用ファイル、リンク境界を確認します。
